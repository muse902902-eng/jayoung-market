# JAYOUNG ON

라이프스타일 쇼핑 홈페이지 시연 서비스입니다. HTML, CSS, JavaScript로 제작했으며 별도 빌드 없이 `dist/`를 정적 호스팅할 수 있습니다.

## 기능
상품 검색, 카테고리 필터, 가격 정렬, 상품 상세, 찜, 장바구니 수량 변경·삭제·합계, 최근 본 상품, 쿠폰 시연.
찜과 장바구니는 브라우저에 저장됩니다. 실제 회원가입, 주문, 결제 및 배송은 제공하지 않습니다. 상품·가격·브랜드·혜택은 예시입니다.
배너 SVG는 이 프로젝트를 위해 직접 작성했으며, 사용자 업로드 이미지의 사진 파일은 포함하지 않습니다.

## 배포
GitHub Settings > Pages에서 GitHub Actions를 선택합니다. main 브랜치 업데이트 시 `.github/workflows/pages.yml`이 dist 폴더를 배포합니다.

## 운영 담당 업무
- 브랜드·상품 운영: 상호, 로고, 상품, 가격, 재고와 사용 가능한 제품 이미지 확정
- 개발: 회원 인증, 서버 데이터베이스, 주문·결제·재고·배송 연동
- 고객 응대: 고객센터, 배송 및 반품·교환 기준 등록
- 배포 관리: GitHub Actions 결과와 공개 접속 상태 확인

실제 판매 기능을 연결하기 전에 사업자 정보와 서비스 운영 정책을 실제 운영 내용에 맞춰 등록해야 합니다.
